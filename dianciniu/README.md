# 电磁牛

把磁力链、种子文件，或直接把视频/文件转发给 Telegram 机器人，自动下载到你的飞牛 NAS。

**三条下载路径，一个机器人搞定：**

- **磁力 / 种子**：内置静态编译的 qBittorrent 引擎，不用另外装下载器
- **转发视频 / 文件（≤20MB）**：直接把视频或文件转发给机器人即可保存到 NAS
- **转发视频 / 文件（>20MB）**：走 tdl **高速通道**（MTProto 直连，不限大小）。第一次用时给机器人发 `/tlogin`，按提示用手机 Telegram 扫码登录一次就行，不用申请任何凭据

- **下载任务带卡片和按钮**：`/status` 里每个 BT 任务都有一行 `[⏸][▶️][🗑]` 按钮，删除要点两次确认；大文件下载有进度卡片，带 **[取消]** 按钮
- **原生应用，不依赖 Docker**：引擎与服务都打包在应用里

- 下载位置可选「应用文件区」或你授权的目录
- 支持做种策略、上传/下载限速、磁盘余量告警
- 带一个状态页（飞牛桌面里的应用入口），进度条与 Telegram 里一致

## 开始使用

1. 在 Telegram 找 [@BotFather](https://t.me/BotFather) 创建机器人，拿到 Token
2. 安装时填入 Token；**自己的用户 ID** 可以留空 —— 先启动应用，给机器人随便发条消息，它会把你的 ID 回给你，再填到「应用设置 → 配置」里
3. 把磁力链、`.torrent` 文件，或视频/文件转发给机器人即可

## 命令

| 命令 | 作用 |
|---|---|
| `/status` | 看任务与进度（带序号） |
| `/cancel 序号` | 暂停任务，保留已下载的文件 |
| `/resume 序号` | 继续任务 |
| `/delete 序号 confirm` | 删除任务及其文件（二次确认） |
| `/where` | 看文件保存位置 |
| `/id` | 查自己的 Telegram 用户 ID |
| `/diag` | 出问题时把这段发给开发者（含脱敏后的日志） |
| `/help` | 帮助 |
| `/tlogin` | 大文件高速通道扫码登录（第一次用前做一次） |

## 下载完会主动告诉你

磁力/种子下完（或出错）时机器人会主动回一条，不用一直发 `/status` 问。
卡住不动的任务会在 `/status` 里附一句原因与建议（最常见的是没人做种的死种）。

转发的视频/文件会按类型分到 `telegram/` 下的 `video / music / image / other` 子目录；
磁力/种子只给任务贴分类标签（**不动文件** —— BT 的文件按路径做校验与做种，搬动会坏）。

## 关于大于 20MB 的转发文件

Telegram 官方接口对文件下载有 **20MB** 上限。更大的转发走 tdl **高速通道**（MTProto 直连，
不限大小，多线程 + 断点续传）。

第一次用之前给机器人发 `/tlogin`，按提示用手机 Telegram 扫码登录一次（用的是你自己的
Telegram 账号，只做一次）。之后 >20MB 的转发自动走高速通道，中途断了会自动重试，
必要时续传，**不需要你重发**。

但有一点必须说清楚：**能不能收下大文件，最终取决于这台 NAS 能不能稳定地连到 Telegram**
（大文件走的是 Telegram 的数据中心连接，不是普通网页请求）。

- **网络稳定**（直连可用，或系统级代理 / 路由器 TUN）→ 转发多大都行；
- **只能靠应用级代理** → 高速通道也吃同一个代理（和应用自身的收发走同一个），一般也能收；
- **代理只按域名分流、不接受"目标是 IP"的连接** → 大文件会失败。这时应用会**直接告诉你原因**，
  不会让你干等；磁力、种子与 20MB 以内的文件不受影响。

## 连不上 Telegram？

大陆家宽常常直连不了 `api.telegram.org`（域名解析被污染或连接超时）。在「应用设置 → 配置
→ 网络代理」填上代理即可（`http://` 或 `socks5://`，安装时也能直接填）。

填了代理之后，磁力、种子、指令、20MB 以内的转发**以及大文件高速通道**都走它
（tdl 吃 `--proxy`）。注意：走代理的字节全额计入代理流量，磁力/BT 流量不走这个代理。

有一点要留意：**大文件连的是 Telegram 的数据中心 IP，而很多代理只按域名分流**。如果你的代理
不接受"目标是 IP"的连接，高速通道会失败；应用会**直接告诉你原因**，并用 `selftest`
告诉你需要在代理端放行哪些网段。连不上时应用不会退出，状态页会说明卡在哪一步，网络恢复后自动接上。


## 关于做种与限速

默认「下完即停止上传」，省上行带宽。PT 站需要保种的话，在安装向导或「应用设置 → 配置」里
改成「不限制」或按分享率/时长。上传、下载速度也可以限速。

更多细节（BT 端口、并发数、磁盘告警阈值等）都有默认值，不动也能用。
