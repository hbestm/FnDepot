# 安装包存放说明

本目录**不再存放 .fpk 文件**（单包约 54MB，放进 git 会让仓库越来越大）。

安装包统一发布在 GitHub Releases：

- 发布页：https://github.com/hbestm/FnDepot/releases/tag/dianciniu
- 直链格式：`https://github.com/hbestm/FnDepot/releases/download/dianciniu/<文件名>`

各版本的下载地址以仓库根目录 `fnpack.json` 里
`apps.dianciniu.releases.<版本>.packages.<架构>.download_url` 为准。
