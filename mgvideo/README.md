咪咕的官方电视直播源，默认占用端口 7788。
内网地址可写 http://127.0.0.1:7788
直接将此地址添加到 OmniBox 的直播资源，电视直播即可播放，注意类型选择 M3U

> 注意事项
>
> 1. 登录后使用不保证安全，请谨慎使用
> 2. 需要国内 IP 才可正常访问
> 3. 尽量内网使用，不推荐代理到外网使用。

## 配置

安装时填写的选项，之后都可以在飞牛「应用设置」里修改，保存后容器自动重启生效。<br>
配置信息如下:

| 变量名          | 默认值 | 类型    | 介绍                                                                                      |
| --------------- | ------ | ------- | ----------------------------------------------------------------------------------------- |
| muserId         |        | string  | 用户 id，可在网页端登录获取，可留空                                                       |
| mtoken          |        | string  | 用户 token，可在网页端登录获取，可留空                                                    |
| mport           | 7788   | number  | 本地运行端口号                                                                            |
| mrateType       | 2      | number  | 画质：2 标清 / 3 高清 / 4 蓝光 / 7 原画 / 9 4K（蓝光及以上需要登录且有 VIP）              |
| menableHDR      | true   | boolean | 是否开启 HDR                                                                              |
| menableH265     | true   | boolean | 是否开启 h265（原画画质），开启后可能存在兼容性问题，比如浏览器播放没有画面               |
| mupdateInterval | 6      | string  | 节目信息更新间隔，单位小时，不建议设置太短                                                |
